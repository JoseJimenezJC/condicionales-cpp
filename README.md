# condicionales-cpp

Ejercicio de práctica en C++ sobre estructuras condicionales.

## Qué hace

- Determina si un número ingresado es **par o impar**.
- Determina si un número es **positivo, negativo o cero**.
- Dado tres números, encuentra **cuál es el mayor**.

## Compilar y ejecutar

```bash
g++ main.cpp -o prog
./prog
```
